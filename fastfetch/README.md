# Fastfetch Image Notes

## Sixel Images

Detailed SIXEL creation steps are in [sixel.md](sixel.md).

Quick command:

```powershell
magick .\input.jpg -resize 250x sixel:output.sixel
```

The width `250x` matches the current Fastfetch padding in this setup.
